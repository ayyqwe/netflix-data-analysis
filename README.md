# Netflix Content Analysis (Python & EDA)

## About The Project
This project presents an Exploratory Data Analysis (EDA) of the Netflix titles dataset[cite: 6]. The goal is to uncover key insights regarding content distribution, production focus, and trends between movies and TV shows.

## Key Technologies
- **Python**[cite: 6]
- **Pandas** (Data Cleaning & Manipulation)[cite: 6]
- **Seaborn & Matplotlib** (Data Visualization)[cite: 6]

## Key Findings
- **Content Ratio:** The dataset consists of movies (~65%) and TV shows (~35%).
- **Production Hubs:** Content creation is heavily concentrated in major countries like the United States, India, and the United Kingdom.

## Project Structure
- `netflix-data-analysis.ipynb` — Complete Jupyter Notebook containing data loading, preprocessing, visualizations, and insights[cite: 6].

## How to Run
1. Download the `.ipynb` file or clone the repository.
2. Open it in Google Colab or Jupyter Notebook.
3. Run all cells sequentially.
